# 🍽️ Panjtara – Restaurant Website

Panjtara is a responsive restaurant website for a traditional Pakistani restaurant in Rawalpindi. It has an animated hero slider, a menu, deals and discounts, and an online table reservation form. It is built with HTML, CSS and JavaScript.

![Panjtara Desktop Preview]<img width="1280" height="1024" alt="image" src="https://github.com/user-attachments/assets/e5ba949e-6fd4-4310-928d-cd9bec95e5a7" />


**🔗 Live Demo:** https://zaib058.github.io/Panjtara/

---

## ✨ Features

- Fully responsive layout for mobile, tablet and desktop
- Hero slider with three slides and previous/next controls
- Menu page and a Deals & Discounts page
- Featured special dish with discounted pricing
- Online reservation form (name, phone, party size, date, time, message) powered by Formspree
- Animated UI: preloader, sliding buttons, glowing deals button, parallax images
- Mobile slide-out navigation
- Cart functionality 

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript (vanilla)
- [Ionicons](https://ionic.io/ionicons)
- [Google Fonts](https://fonts.google.com/) (DM Sans, Forum)
- [Formspree](https://formspree.io/) for the reservation form

## 🚀 Getting Started

### Prerequisites

- [Git](https://git-scm.com/downloads)
- A modern web browser

### Run Locally

```bash
git clone https://github.com/Zaib058/Panjtara.git
cd Panjtara
```

Then open `index.html` in your browser. For a local server, you can use the VS Code *Live Server* extension or run:

```bash
python -m http.server 8000
```

and visit `http://localhost:8000`.

## 📬 Reservation Form Setup

The form sends submissions through Formspree. To use your own endpoint, replace the `action` URL on the `<form>` in `index.html` with your Formspree form URL.
